Existing installation (preserves your local Database.js/configuration)
1. Upload the new ZIP beside your service directory, then:

   cd ~/services
   staging_dir=$(mktemp -d /tmp/jsfc-influx-diagnostics-XXXXXXXX)
   unzip -q JSFC_Redis_Trip_Service_8_Workers.zip -d "$staging_dir"
   bash "$staging_dir/jsfc-trip-service/scripts/install-influx-diagnostics.sh" "$HOME/services/jsfc-trip-service"

2. Restart only the trip workers so changed code/configuration is loaded:

   cd ~/services/jsfc-trip-service
   pm2 restart ecosystem.config.cjs --only jsfc-trip-0,jsfc-trip-1,jsfc-trip-2,jsfc-trip-3,jsfc-trip-4,jsfc-trip-5,jsfc-trip-6,jsfc-trip-7 --update-env

   node scripts/check-worker-history.cjs JH02AK7064 2026-10-02T03:03:10Z 2026-10-02T09:03:10Z

   at most two pages. Optional final argument 1..10 controls the page count.

   The CLI loads the same modules in the same order, but cannot inspect the
