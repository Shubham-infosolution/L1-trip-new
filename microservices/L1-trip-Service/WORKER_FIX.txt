Changes in this release
1. src/history-replay.js: count missing payloads before adding a preceding
   source observation. Complete batches now report zero instead of -1; a real
   missing payload is no longer hidden by the extra predecessor.
2. src/worker-metrics.js and src/worker.js: separate history enqueue attempts,
   records scanned, predecessor observations and successful packet flushes.
   Preserve processed_packets as a compatibility alias for history enqueue
   attempts. Include build, sampled_at and last_successful_flush_at in health.
   Record successful flush only after MySQL commit AND Redis acknowledgement.
   Sample pending vehicles after processing rather than reporting the old list.
3. src/location-log.js and worker.js: suppress identical per-trip location logs
   within one refresh interval. Changes in packet, trip or tracked state remain
   visible. Keep a periodic refresh and discard inactive logging keys.
4. Worker invalid_geofence logs identify the side, affected action, route,
   store, coordinates and radius. Missing destination still does not prevent
   a valid source departure. Keep pool logging configuration as supplied.
5. operational-health.cjs / conclusions.cjs: distinguish recent worker errors
   from collector read errors and pre-restart PM2 log entries. Parse current
   process/PID and a two-minute recent-error window. Include worker progress
   and service blockers in each trip/vehicle conclusion and worker summaries.
6. One normal queued packet is informational; draining queues are labelled as
   progressing. A queue of 1,000+ packets is a reporting warning when no queue
   progress is observed. GPS event age is not used as queue residence time.
7. Conclusions include route/store IDs, source-IN/OUT history evidence and
   clear master-data actions. Negative old counters are labelled as monitoring
   defects, never as proof that packet payloads have been lost.

It first validates syntax and backs up existing files. All six are installed
before restarting jsfc-trip-0 through jsfc-trip-7. Database.js, configuration,
MQTT subscriber, Redis queues and MySQL schema are not replaced. There are no
new dependencies or helper MySQL tables. This package contains complete versions
of these six files; retain any separate local customizations when reviewing
the backups. Installing only worker.js without its new helper is insufficient.
